Tentang Saya

Perjalanan singkat menuju dunia pengembangan perangkat lunak

Saya memulai perjalanan belajar coding dari rasa penasaran terhadap bagaimana sebuah website bisa dibangun dari nol. Dari situ saya mulai mempelajari HTML, CSS, dan JavaScript, lalu memperluas ke Python untuk membuat skrip dan alat bantu otomasi kecil.

Saat ini saya sedang mendalami AI prompt engineering — mempelajari cara bekerja sama dengan model AI untuk mempercepat proses belajar dan membangun proyek. Saya percaya bahwa belajar terbaik datang dari praktik langsung, jadi sebagian besar proyek di sini lahir dari eksperimen pribadi.

Latar belakang akademik saya berasal dari Northern Border University, dan saya terus mengasah kemampuan lewat proyek-proyek kecil di waktu luang.
